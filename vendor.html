Who we are

Tagwright is operated by Frank Gilroy. It fixes PDF files so they work with screen readers and returns a record of how each file was checked.

What we do

PDF accessibility remediation. We tag headings, lists, tables, figures and reading order, set the language and title, run OCR on scanned pages, write descriptions for images, and validate the result with the open-source veraPDF validator against PDF/UA-1. PDF only for now: Word, PowerPoint and EPUB are not offered yet.

Prices

We sell prepaid page credits. A simple page uses 1 credit, a complex page (tables, forms, many figures) uses 3, and a scanned page that needs OCR uses 1 more. Credits are valid for 12 months and are only used for pages actually processed.

What you receive

For each file: the fixed PDF, and an evidence pack containing the veraPDF PDF/UA-1 report; a checkpoint table that labels each item as machine-verified, automated review or human-sampled; a manifest of image descriptions; a table-header manifest; the first 40 tagged elements in reading order; and SHA-256 hashes of the input and output with a signed ledger entry.

What still needs a person

A machine check cannot judge whether an image description says what matters, whether the reading order makes sense, or whether headings and tables match your intent. The evidence pack says which checks fall where. Image descriptions are machine-written and cross-checked by a second, independent pass, and they can still be wrong. A file that loses text or ends up with almost nothing tagged is held for a manual check and is neither delivered nor charged for. A file that fails a veraPDF rule is delivered with that rule listed in its report.

In our own test of 150 real US government PDFs, 82% passed all three of our automated checks (veraPDF PDF/UA-1, no text lost, and the text covered by the tags). The test does not score image descriptions. A few kinds of file are not handled yet, for example some scanned or image-heavy documents.

Data handling

  • Files are uploaded over HTTPS and stored with Netlify during processing.
  • Source files and results are deleted no later than 30 days after delivery.
  • We keep a ledger of SHA-256 hashes and job metadata, never document content.
  • Text and page images may be processed by Anthropic solely to describe images and check structure. They are not used to train models.
  • Subprocessors: GitHub (website hosting), Netlify (upload storage and file delivery), Polar (payments, as merchant of record), Anthropic (image and text processing for submitted files).
  • Please do not send protected health information or student education records.

Not available yet

A VPAT or accessibility conformance report, a SOC 2 report, an insurance certificate, a human-reviewed quality tier, and Word or PowerPoint remediation. If your office needs one of these before buying, tell us and we will say plainly whether we can provide it.
